# Config

Place your credentials here:

- `google-oauth-client.json` — OAuth client credentials from Google Cloud Console
- `google-oauth-tokens.json` — generated after running `scripts/setup_oauth.py`
- `fireworks-api-key.txt` — Fireworks AI API key (optional)
- `deepgram-api-key.txt` — Deepgram API key (optional)

⚠️ These files are in `.gitignore` and will NOT be committed.
